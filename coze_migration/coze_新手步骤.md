## 第 4 步：认识“工作流画布”（很重要，先看这段）
以后每建一条工作流都长这样：
- 左边一排「**节点**」可以拖到中间画布。常用：**开始 / 结束 / 大模型 / 代码 / 数据库 / 选择器 / 卡片**。
- 节点之间用线连起来，数据从左流向右。
- **代码节点怎么用**（核心操作，4 条工作流都会用到）：
  1. 拖一个「**代码**」节点到画布，连线接好。
  2. 点这个节点，右上角选语言「**Python**」。
  3. 把对应 `.py` 文件的**全部内容复制**粘贴进代码框（里面已经有 `def main(...)` 函数，不用改）。
  4. 节点下方「**输入**」：给每个参数起个名字，并选「来源」= 上游节点的某个输出变量（下每个工作流会告诉你填什么）。
  5. 节点「**输出**」会自动按 `return` 的字典生成变量名，下游靠这些名字引用。
- 保存：画布右上角「**保存**」，别忘点。

## 第 5 步：建第 1 条工作流 —— 预警中心（最简单，先练手）
1. 工作流页 → 「**新建工作流**」→ 名称 `cola_alert` → 创建。
2. 画布上默认有「开始」和「结束」节点。
3. 拖一个「**数据库**」节点放在中间：
   - 连「开始 → 数据库 → 代码 → 卡片 → 结束」。
   - 数据库节点选「**查询**」，表选 `shipment_ledger`，条件留空（查全部），输出起名 `shipments`。
   - 再拖第二个「数据库」节点查 `inventory_simple`，输出起名 `inventory`。
4. 拖一个「**代码**」节点：
   - 粘贴 `coze_code_nodes/alerts.py` 全部内容。
   - 输入参数：`shipments` 来源=上面数据库1的 `shipments`；`inventory` 来源=数据库2的 `inventory`。
   - 输出会自动有 `delay` / `low_stock` / `expiry` / `total_count` 等。
5. 拖一个「**卡片**」节点：
   - 连代码节点输出。卡片里写：「预警总数：{{total_count}}；逾期：{{delay}}；低库存：{{low_stock}}；效期：{{expiry}}」。
6. 点「**试运行**」→ 因为表里没数据，会显示 0 条，说明链路通了。保存。

✅ 第一条跑通！后面 3 条同理，只是换节点和文件。

## 第 6 步：建第 2 条 —— AI 问答 `cola_qa`
1. 新建工作流 `cola_qa`。
2. 「开始」节点加一个输入变量：`query`（文本）。
3. 拖「**大模型**」节点：
   - 提示词粘贴 `coze_prompts.md` 里「**二、AI问答·意图识别**」整段。
   - 引用变量 `{{query}}`。
   - 输出：在节点输出里定义 `intent`、`date_str`、`grade`（按提示词里的 JSON 字段）。
4. 拖「**选择器**」节点，按 `intent` 分两支（精确 / 通用）。
5. **精确支**：数据库查 `shipment_ledger` 输出 `rows` → 代码节点粘贴 `query.py`（输入 `rows`/`query_date`=`date_str`/`grade`）→ 卡片显示结果。
6. **通用支**：数据库查两表拼 `context` → 代码节点粘贴 `qa.py`（输入 `question`=`query`）→ 大模型节点粘贴 `coze_prompts.md`「**三、通用问答**」→ 结束输出 `answer`。
7. 保存，试运行一句「今天库存多少」。

## 第 7 步：建第 3 条 —— 调运录入 `cola_transport`
1. 新建工作流 `cola_transport`。
2. 「开始」加输入 `text`（文本，用户粘 CSV 或口语）。
3. 拖「**代码**」节点粘贴 `csv_io.py`（输入 `csv_text`=`text`，输出 `rows`）。
4. 拖「**代码**」节点粘贴 `classify.py`（输入 `rows`，输出 `rows` 带分类）。
5. 拖「数据库」查 `shipment_ledger` 全部，输出 `existing`。
6. 拖「代码」节点粘贴 `validate.py`（输入 `rows` + `existing`，输出 `valid_rows`/`errors`/`dup_rows`）。
7. 拖「数据库」→「新增」，表 `shipment_ledger`，数据来源=`valid_rows`，输出 `inserted_count`。
8. 拖「卡片」显示：成功 `inserted_count` 条、重复 `dup_rows`、错误 `errors`。
9. 保存。试运行：把测试 Excel 另存为 **CSV(UTF-8)**，复制全文粘到 `text` 试运行。

## 卡住了怎么办
- 节点连线不会：把两个节点都点一下，从一个节点的小圆点拖到另一个节点。
- 代码节点报错：检查「输入」的来源变量名是否和上游输出完全一致（大小写、下划线都要一样）。
- 不知道粘哪个文件：回到本文件对应步骤，都写了文件名。
- 把报错截图发我，我告诉你那一步点什么。
